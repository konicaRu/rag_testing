## Формат manifest

CSV: UTF-8 без BOM, разделитель — запятая, перевод строк — CRLF, значения экранированы по правилам CSV. Для чтения достаточно стандартного CSV-парсера.

- document_id — стабильный ID G001–G200 внутри этой выборки.
- source_type — confluence или manual.
- source_path — проверенный путь относительно rag_a3.
- page_id — ID страницы Confluence; пуст для ручных документов.
- local_id — ID импорта ручного документа; пуст для Confluence.
- title — название из YAML исходного документа.
- primary_category — одна основная категория; документ учитывается в квоте один раз.
- related_entities — JSON-массив тематических тегов внутри CSV-поля. payment_support обозначает дополнительный платёжный контекст вне десяти ключевых сущностей.
- knowledge_type — основной тип знаний: definition, rule, process, relationship, exception, reference.
- document_status — unknown или possibly_outdated; unknown не означает confirmed.
- content_sha256 — SHA-256 полных исходных байтов файла, включая YAML и исходные переводы строк. Это не хеш очищенного текста из предыдущего аудита.
- updated_at — значение confluence_updated из YAML, если оно известно. Для ручного документа оно может отражать дату файла при импорте, а не дату встречи или авторского обновления.
