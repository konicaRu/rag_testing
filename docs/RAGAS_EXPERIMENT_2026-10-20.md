## Ошибки и решения

### A. Импорт Ragas

Ошибка ModuleNotFoundError: No module named 'langchain_community.chat_models.vertexai' связывалась с несовместимой версией langchain-community. В интерактивном эксперименте выполнено закрепление langchain-community==0.4.1; после перезапуска kernel импорт KnowledgeGraph успешен. Сейчас версия подтверждена метаданными, переустановка не выполнялась.

### B. Параметр mode в llm_factory

mode=instructor.Mode.MD_JSON через llm_factory приводил к TypeError: instructor.process_response.handle_response_model() got multiple values for keyword argument 'mode'. Не передавать mode этим путём; явный режим задавать при создании Instructor-клиента.

### C. HTTP 400 и response_format

LM Studio отвечал: 'response_format.type' must be 'json_schema' or 'text'. Диагностика фактического запроса показала json_object; три повтора отклонены. Прямой локальный OpenAI-совместимый запрос с json_schema успешен за 8,3 секунды. Это не означает совместимость того же режима через обёртки.

### D. Нерабочий JSON_SCHEMA через Instructor

instructor.from_openai с Mode.JSON_SCHEMA вместе с InstructorLLM продолжал отправлять json_object и получать HTTP 400. Эту конфигурацию не считать рабочей.

### Проверенный путь

OpenAI-совместимый клиент локального endpoint: timeout=180.0, max_retries=0; instructor.from_openai(client, mode=instructor.Mode.MD_JSON); InstructorLLM(client=structured_client, model=qwen2.5-14b-instruct-1m, provider=openai, temperature=0.1, max_tokens=300). Значение служебного поля авторизации в память не переносится.

ragas_llm.generate с коротким искусственным вопросом вернул Париж; сохранённый вывод подтверждает успех. Через этот объект успешно выполнен KeyphrasesExtractor. Совместимость остальных экстракторов и генераторов требуется проверять отдельно; max_tokens=300 — параметр короткой пробы, не утверждённая настройка генерации полного датасета.

TqdmWarning: IProgress not found не блокировал опыт; исправление не выполнялось.
