# rag_testing

Проект для подготовки эталонных наборов и воспроизводимой проверки локального RAG: качества поиска, полноты контекста и правильности ответов.

## Как будем работать

Основной интерфейс — Jupyter Notebook в VS Code. Перед каждой ячейкой будет объяснение, значимые строки кода будут прокомментированы. Пользователь запускает ячейки и просматривает результаты внутри ноутбука.

Поток: тема → автоматическая подборка документов → проверка источников → генерация вопросов и ответов → утверждение эталона → запросы к RAG → расчёт метрик.

Первый пилот — тема «Партнёр в системе А3: определение и роль». Начинаем с небольшого пакета материалов; вручную перебирать весь корпус не требуется.

## Планируемые ноутбуки

1. `01_select_documents.ipynb` — подбор пакета по теме: BM25 + смысловой поиск.
2. `02_generate_testset.ipynb` — вопросы, ответы и цитаты из утверждённых источников.
3. `03_run_evaluation.ipynb` — запросы к RAG и отчёт.
4. Тестирование агентов и инструментов — отдельный будущий этап.

Эти файлы пока не созданы. Команды установки будут добавлены после выбора и проверки зависимостей.

## Какие результаты получим

- таблицу кандидатов для ручной проверки;
- утверждённые вопросы и эталонные ответы;
- разметку релевантности источников;
- отчёты отдельных запусков и сравнение конфигураций.

Для просмотра используем Excel, для автоматической обработки — JSONL/CSV. Метрики поиска и оценки текста ответа сохраняем отдельно.
